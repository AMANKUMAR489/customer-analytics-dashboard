# Customer Analytics Dashboard (Power BI + Live)

## Overview
This project focuses on analyzing customer behavior and operational performance using a Power BI dashboard and a live version for interactive analysis.
The goal was to understand how different factors like delivery time, order volume, and customer ratings affect overall performance.

## What I Worked On
- Analyzed customer and order data to identify patterns and drop-offs
- Built dashboards to track key metrics like delivery rate, KPT, and rider wait time
- Built and tested a live version of the dashboard to understand real-time data tracking
## Key Metrics Tracked
- Delivery Rate  
- KPT (Kitchen Prep Time)  
- Rider Wait Time  
- Rejection Rate  
- Customer Ratings
